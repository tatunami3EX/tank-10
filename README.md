# 🎮 対戦型トップダウン戦車アクション『TANK-10』

最大20人で遊べるオンライン対戦型トップダウン（見下ろし視点）戦車アクションゲームです。
ホストが部屋を作ると**ホスト自身がゲームサーバー兼オーソリティ**となり、参加者とP2Pで直接接続！
壊せる壁ブロックが配置された64×64（または大規模96×96）のプロシージャル生成ステージで、制限時間5分内に生き残りとキル数を競い合います。

---

## 🌟 特徴 & 新機能ハイライト

1. **ホストが部屋を立てたらホスト自身がサーバーになる (完全P2P分散型)**:
   - 専用サーバーマシン不要！ホストがブラウザで部屋を作ると、そのブラウザ上でゲームエンジン・物理・AIシミュレーションがリアルタイム実行されます。
   - 他のプレイヤーは5文字の「部屋コード」を入力するか招待URLを開くだけで、ホストサーバーに即座に接続されます。
2. **ランダムスポーンシステム (1〜20のスタート地点から完全ランダム配分)**:
   - マップ上の1から20箇所のスタート地点の中から、試合開始時に重複なしで完全にランダムにプレイヤーやボットへ配置されます。毎回異なる位置からスタート！
3. **スマホ完全対応 ＆ ホーム画面スクロール改善**:
   - スマホでロビー画面を開いた際にも指で上下スムーズにスクロール可能！
   - ブロスタ風デュアルスティック操作（左：移動、右：ドラッグで照準・指を離して発射）。
4. **チーム変更 ＆ 👑 1 vs 19 (ホスト対全ボット) プリセット**:
   - ロビーでプレイヤーやボットのチームを個別に変更可能（Blue vs Red、Team 1〜10）。
   - **「👑 1 vs 19 (ホスト対全ボット)」** ボタンを押せば、ホスト1人(青) vs 全ボット19人(赤) の大防衛戦がワンクリックでセットアップ可能！
5. **ボットの属（戦車タイプ・チーム）のカスタマイズ**:
   - ホストは各ボットの戦車属性（スタンダード、アサルト、ヘビー、スナイパー、ブレイカー）を個別に変更可能。
   - 「🤖 Bot戦車」セレクターからボット軍団全員の戦車を一括変更することも可能！
6. **マルチデバイス対応（3つの操作方式） ＆ 照準ガイド**:
   - **① PC（マウス ＋ キーボード）※推奨**: `WASD`で移動、`マウス`で360度照準、`左クリック`で発射。
   - **② PC（フルキーボード）**: `WASD`で移動、`J/L`で砲塔旋回、`K`または`Space`で発射。
   - **③ モバイル（タッチ操作）**: 左画面の仮想移動パッド ＋ 右画面の仮想エイム＆発射パッド。
   - **🎯 照準＆射程ガイドライン**: 自機の砲身から向いている方向へ**射程限界ライン**をリアルタイム表示！壁に遮られた場合は衝突点（インパクトマーク）を表示し、弾がどこまで届くか一目で判断可能。
   - **🔍 視界ズーム仕様**: プレイヤー操作時は**ズーム率150%（クローズアップ迫力視点）に固定**（プレイヤー側の誤操作ズームは無効化）。観戦時のみ全体引き（俯瞰）や自由ズームが可能。
4. **毎試合変わる 64×64 マップ**:
   - 外周の防壁、内部のスチール柱（破壊不能壁）、迷路状のレンガ壁（破壊可能、HP:50）。
   - BFS（幅優先探索）開通アルゴリズムにより、初期導線が遮断されない安全性を保証。
5. **充実のロビー＆ホスト機能 ＆ Bot AI補充**:
   - プレイヤー名変更（自由入力）、戦車タイプ選択、リアルタイム性能ゲージプレビュー。
   - ホスト権限: ゲーム開始、観戦専用モード切替、**「Botで10人に補充」**（1人でも即座に白熱の10人対戦を楽しめます！）。
6. **リザルト画面（順位表）＆ リマッチ機能**:
   - 生き残り順（最後まで生存が1位）、キル数タイブレークで1st〜10thを正確に判定。
   - ホストが「ロビーへ戻る」を押すと、全クライアントが同期してロビーへ戻り再戦可能。
7. **広域観戦システム（マップ全体俯瞰 ＆ ズーム対応）**:
   - **🗺️ マップ全体俯瞰 (引きカメラ)**: 観戦中、ワンクリックで64×64グリッド（2304×2304px）全体が画面にすっぽり収まる超引きアングルに切り替え可能。
   - **🎯 プレイヤー追従**: 個々の生存プレイヤーをカメラ追従（◀ PREV / NEXT ▶で切り替え）。
   - **ズーム調整（自由な引き/寄り）**: `🔍−` / `🔍＋` ボタンやマウスホイール操作で、0.18倍（超引き）〜2.0倍（拡大）までシームレスにズーム調整が可能。
   - 引き画面でも戦車・弾丸・レーザー・頭上HPがパッと把握できるネオンハイライト表示を完備。
8. **ゼロ外部依存 ＆ Web Audio API立体音響（空間オーディオ）**:
   - 外部ライブラリ（npm install等）一切不要のピュアNode.js（RFC 6455 WebSocket標準サーバー）。
   - **🎧 近距離空間オーディオ**: マップ全体の騒音を防ぐため、**自機を中心とした半径1300px（スナイパー射程1200px＋100px）以内のみ音が聞こえる空間減衰＆左右ステレオパンニング**を実装！
   - Web Audio APIにより、発射・被弾・壁粉砕・大爆発音を即座にリアルタイム合成。

## 🌐 WebRTC (PeerJS) による完全P2P遠隔対戦

中央サーバーを経由せず、プレイヤー同士のブラウザ間で直接暗号化通信を行うため、**ポート開放・トンネル・サーバー起動が一切不要**で、Wi-Fiが違ってもラグの少ない対戦が可能です。

```
[ホスト (PC/スマホ)]  ---- 招待URL / 5文字部屋コード ---->  [ゲスト (スマホ/PC)]
         │                                                      │
         └─────────── WebRTC P2P 直接データ通信 ────────────────┘
                     (Ping: 約10〜30ms の超低遅延)
```

### 1. 部屋を作る（ホスト / Player 1）
1. ゲームを開き、ロビーヘッダーの **「🛡️ 部屋を作る (HOST)」** をクリックします。
2. 5文字の部屋コード（例: `CYBER`）が自動発行されます。
3. **「🔗 招待URLコピー」** を押してLINEやDiscordで友達に送るか、**「📱 スマホQR」** をスマホのカメラで読み取ります。

### 2. 部屋に入る（ゲスト / Player 2〜10）
* **招待リンクをもらった場合**: ブラウザで開くだけで自動でホストに接続されます！
* **コードをもらった場合**: 画面右上の入力欄に5文字コードを入れて **「参加 (JOIN)」** を押すだけで接続されます。

## 🌍 GitHub Pages に無料公開していつでも遊ぶ方法（最もおすすめ）

このフォルダの内容を GitHub にアップロードするだけで、世界中誰とでもPC・スマホから常時遊べるようになります：

1. GitHub で新しいリポジトリを作成します（例: `tank-10`）。
2. このフォルダの内容をリポジトリにアップロード（push）します。
3. リポジトリの **Settings > Pages** を開き、Source を `Deploy from a branch (main / root)` に設定して「Save」。
4. 数分で **`https://<ユーザー名>.github.io/<リポジトリ名>/`** という固定URLが完成します！
5. 相手にそのURLを送るだけで、サーバーを立ち上げていなくても24時間いつでもスマホや友達と対戦できます。

### ① Wi-Fiが違う場合（スマホ4G/5G・外出先・友達の家）※おすすめ！
自宅のWi-Fiとは別の回線（スマホのモバイル通信や友達のPC）から接続する場合は、**インターネット公開トンネル**を使用します。

1. **[`start-online.bat`](file:///C:/Users/tatun/.gemini/antigravity/scratch/tank-10/start-online.bat) をダブルクリックで実行**します。
2. 画面に以下のような公開URL（HTTPS / WSS対応）が表示されます：
   `https://xxxxxxxx.a.pinggy.link`
3. スマホのブラウザ（SafariやChrome）でそのURLを開くか、友達に送るだけで、**回線やWi-Fiが違っても一瞬で繋がります！**

> 🔒 **合言葉（Room Code）について**:
> - ロビー画面右上の「合言葉（Room Code）」に同じ合言葉（例: `tank777`）を入力して「入室」を押すか、URLの末尾に `?room=合言葉` を付けて開くだけで、同じ部屋のプレイヤー同士だけでマッチングされます！

---

### ② 同じ家庭内Wi-Fiでスマホから「接続拒否」される場合の解決法
PCとスマホが同じWi-Fiにつながっているのに「接続が拒否されました」と出る原因は、**Windows Defender ファイアウォールがポート3000への外部受信をブロックしているため**です。

1. **[`open-firewall.bat`](file:///C:/Users/tatun/.gemini/antigravity/scratch/tank-10/open-firewall.bat) を「右クリック」→「管理者として実行」** します。
2. ポート3000の受信が許可されます。
3. スマホのブラウザで以下を開いてください：
   👉 **http://192.168.0.10:3000** （PCのIPアドレス）
   ※ ロビーの「📱 スマホ接続」ボタンを押せば、カメラで読み取れるQRコードも表示されます。
